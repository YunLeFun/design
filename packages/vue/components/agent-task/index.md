---
title: Agent Task
title_zh: 机器人任务
---

展示当前任务、执行状态、任务标识与等待原因。可以用于执行中、等待审批、完成、失败或空闲场景。没有可靠进度时不显示百分比，也不会将忙碌状态解释为完成。

## Props

| 属性          | 说明                             | 类型            | 默认值 |
| ------------- | -------------------------------- | --------------- | ------ |
| `title`       | 区域标题                         | `string`        | 必填   |
| `state`       | 展示状态                         | `YlfAgentState` | 必填   |
| `statusLabel` | 本地化的真实任务状态             | `string`        | 必填   |
| `taskId`      | 可选任务标识，等宽字体并允许换行 | `string`        | —      |
| `description` | 当前状态或等待原因               | `string`        | —      |

## Slots

| 名称      | 说明                                         |
| --------- | -------------------------------------------- |
| `default` | 任务补充信息                                 |
| `actions` | 应用控制的操作，例如查看详情、请求中断或审批 |

审批与中断必须由应用显式处理；卡片没有默认操作，不会把关闭卡片当成批准。实际模型状态未知时使用 `unknown` 并显示后端状态文字。接入方式见[机器人组件](/guide/agent-ui)。
