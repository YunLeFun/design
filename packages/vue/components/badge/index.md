---
title: Badge
title_zh: 徽标
---

缤纷徽标：极光填充或柔色语义，用于标记状态、版本与强调。

## Props

| 属性      | 说明     | 类型                                                      | 默认值  |
| --------- | -------- | --------------------------------------------------------- | ------- |
| `variant` | 风格     | `aurora \| brand \| success \| warning \| danger \| info` | `brand` |
| `round`   | 胶囊圆角 | `boolean`                                                 | `true`  |

## Slots

| 名称      | 说明     |
| --------- | -------- |
| `default` | 徽标内容 |
