title: Card
title_zh: 卡片
---

浮云卡片：大圆角、色染柔影、可选云玻璃通透——卡片像浮在天上的云朵，悬停轻轻抬升。

## Props

| 属性        | 说明                  | 类型                        | 默认值   |
| ----------- | --------------------- | --------------------------- | -------- |
| `variant`   | 表面风格              | `soft \| glass \| gradient` | `soft`   |
| `hoverable` | 悬停时轻轻抬升        | `boolean`                   | `true`   |
| `padding`   | 内边距（任意 CSS 值） | `string`                    | `'22px'` |

## Slots

| 名称      | 说明     |
| --------- | -------- |
| `default` | 卡片内容 |
