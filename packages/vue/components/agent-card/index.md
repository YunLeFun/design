---
title: Agent Card
title_zh: 机器人概览
---

机器人控制台的概览容器：身份、说明、状态、连接信息与操作入口。表面、字体与间距读取共享 token；信息卡片保持静止，不使用悬停上浮暗示可点击。

## Props

| 属性          | 说明                           | 类型            | 默认值 |
| ------------- | ------------------------------ | --------------- | ------ |
| `name`        | 机器人名称，作为区域可访问名称 | `string`        | 必填   |
| `description` | 机器人用途或当前项目           | `string`        | —      |
| `state`       | 展示状态                       | `YlfAgentState` | 必填   |
| `statusLabel` | 本地化的状态文字               | `string`        | 必填   |

## Slots

| 名称      | 说明                                     |
| --------- | ---------------------------------------- |
| `avatar`  | 可替换的机器人形象；默认图形仅作装饰     |
| `default` | 连接信息等业务内容                       |
| `actions` | 操作按钮；权限、禁用条件与事件由应用控制 |

组件不接收凭据、不建立连接、不保存审批，也不执行任何操作。名称与说明使用转义文本展示。接入方式见[机器人组件](/guide/agent-ui)。
