title_zh: 选择器

选择器：定位、键盘导航、首字母检索、滚动基于 [reka-ui](https://reka-ui.com)，外观走 token。

## Props

| 属性          | 说明                               | 类型             | 默认值   |
| ------------- | ---------------------------------- | ---------------- | -------- |
| `v-model`     | 选中值                             | `string`         | —        |
| `options`     | 选项 `{ label, value, disabled? }` | `SelectOption[]` | —        |
| `placeholder` | 占位文案                           | `string`         | `请选择` |
| `disabled`    | 禁用                               | `boolean`        | `false`  |
