title: Separator
title_zh: 分隔线
---

分隔线：基于 [reka-ui](https://reka-ui.com)，支持水平 / 垂直与语义化（`decorative` 控制是否对屏幕阅读器可见）。

## Props

| 属性          | 说明   | 类型                     | 默认值       |
| ------------- | ------ | ------------------------ | ------------ |
| `orientation` | 方向   | `horizontal \| vertical` | `horizontal` |
| `decorative`  | 仅装饰 | `boolean`                | `true`       |
