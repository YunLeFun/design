## 品牌标志

`YlfLogo` 使用云乐坊主站的正式标志，默认晴空蓝，随明暗主题切换。云朵作为品牌装饰，与正式标志区分。使用方式见[品牌与界面](/guide/patterns)。

| 属性       | 可选值                    | 默认值     |
| ---------- | ------------------------- | ---------- |
| `size`     | `sm` / `md` / `lg`        | `md`       |
| `layout`   | `vertical` / `horizontal` | `vertical` |
| `wordmark` | `boolean`                 | `true`     |
