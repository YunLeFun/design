title: Progress
title_zh: 进度条
---

进度条：基于 [reka-ui](https://reka-ui.com)（`role="progressbar"` + aria 值），外观走 token，可选极光填充。

## Props

| 属性      | 说明     | 类型              | 默认值  |
| --------- | -------- | ----------------- | ------- |
| `value`   | 当前进度 | `number`          | `0`     |
| `max`     | 最大值   | `number`          | `100`   |
| `variant` | 填充     | `brand \| aurora` | `brand` |
