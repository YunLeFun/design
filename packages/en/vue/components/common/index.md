## Brand logo {#品牌标志}

`YlfLogo` uses the official main site mark with sky blue and theme aware tokens. Decorative clouds are separate from the official logo. See [Brand and interfaces](/en/guide/patterns).

| Prop       | Values                    | Default    |
| ---------- | ------------------------- | ---------- |
| `size`     | `sm` / `md` / `lg`        | `md`       |
| `layout`   | `vertical` / `horizontal` | `vertical` |
| `wordmark` | `boolean`                 | `true`     |
